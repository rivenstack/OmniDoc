# Manual capture checklist

For each live reference capture (customize to your domain):

- Homepage / first viewport
- Primary navigation
- Key listing / browse view
- Key detail view (above the fold)
- Critical data / specifications presentation
- Cart or equivalent commitment step (if any)
- Mobile navigation (~390)
- Mobile filters / secondary chrome
- Validation / error states

Record: date, viewport, URL, login required (yes/no), and notes.
