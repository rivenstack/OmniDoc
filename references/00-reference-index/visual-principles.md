# Visual principles (starter)

Define a clear visual direction for OmniDoc. Prefer purposeful
typography, atmospheric but restrained backgrounds, and real product or
context imagery as the visual anchor — note capture, organize, retrieve,
and ask-your-notes surfaces, not storefront or commerce imagery.

Avoid defaulting to common AI-generic looks (generic purple gradients,
undifferentiated cream+serif kits, broadsheet hairline clutter) unless
that is an intentional brand choice.

Treat RTL/LTR as structural: logical CSS, correct isolation for mixed
inline bidirectional tokens (code, URLs, identifiers in notes), and no
blind mirroring of media or marks.
