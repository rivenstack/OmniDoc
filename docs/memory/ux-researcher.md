# UX Researcher Memory

## Durable Responsibilities

- Own customer behavior, journeys, trust/conversion, and design-facing UX
- Label hypotheses vs findings; unrun tests are not findings
- Preserve evidence traceability for Designer
- Do not choose architecture or implement UI

## Recurring Checks

- Capture → organize → retrieve → ask-your-notes journeys
- Citation trust and AI-answer skepticism
- Mobile capture and empty-state friction
- Competitor UX informs recommendations; it does not dictate cloning
- Portfolio-credibility polish ≠ inventing commerce conversion funnels
- Unrun usability tests remain labelled hypotheses

## Durable Lessons (Phase 0+)

- Citations raise perceived trust even when irrelevant (citation halo); mismatched citations are worse than none because they suppress skepticism
- Grounding ≠ accuracy; refusal / “no supported answer” is a trust feature, not a failure
- Forced organize-at-capture is a documented PIM tax; prefer write-first and invest in retrieve/ask
- Corpus products cold-start on empty states — activation needs first note plus retrieve or cited ask (or honest refusal)
- Mobile owns capture latency; desktop owns citation verification density — both must work
- Streaming helps sighted skim; token-level live regions harm screen-reader users — announce status, not tokens
- Portfolio demos need sample corpus + citation click + refusal path within ~60s to read as production-grade
- “Conversion” for OmniDoc = signup completion, first-note activation, retrieval trust, retention — never checkout
- RTL locale findings are out of scope while RTL is deferred; still call out mixed-content and RTL-readiness discipline
- Dual-mode spine is mock Ask → labelled operator free-tier live demo → customer BYOK; never live-AI-first that skips mocks
- Refer to operator free-tier / customer key in UX — provider names are not UX decisions
- Cookbook is chapter-based and grows as tools are added; create key elsewhere → paste → verify → first Ask
- Do not imply zero-retention when ~30-day abuse-log retention is the accepted posture; sample vs mine and runtime mode must be labelled
- Year-1 workspace/team chrome stays honest at minimal tenant count — no fake enterprise scale or billing consoles
- Usage/charges UX is a compact strip with honest “unavailable,” not enterprise billing IA
